# Contiguous File System Simulator

A C program that simulates a 200 KB disk using contiguous file allocation.

## Features

- Store, access, delete, and list simulated files.
- Track file locations and disk blocks.
- Display the disk's block map.
- Compact the disk to reclaim deleted space.

## Running the Project

You'll need GCC installed and available in Command Prompt.

Open Command Prompt in the folder containing `Lab5.c`.

Compile:

```bat
gcc Lab5.c -o Lab5.exe
